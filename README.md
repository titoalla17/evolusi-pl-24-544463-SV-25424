## Tentang Aplikasi
Aplikasi web pencarian film sederhana berbasis **Laravel** yang terintegrasi dengan **TMDB API**. Proyek ini dibuat untuk mempraktikkan alur kerja pengembangan perangkat lunak modern, mulai dari *Conventional Commits*, *branching strategy*, hingga *Continuous Integration* (CI) menggunakan GitHub Actions.

## Fitur Utama

* Integrasi HTTP Client Laravel dengan penanganan respons kosong atau error.
* Pengujian unit/fitur (*feature testing*) menggunakan PHPUnit dan *HTTP Mocking*.
